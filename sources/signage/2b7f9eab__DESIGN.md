# Column inspector

Inherits OTB Command's forest ink, paper and brass palette. This is a focused model surface, not a new product identity. Adam's brief and standing instruction to choose sensible implementation details replace a redundant design interview for this session; no persistent workflow preference is stored.

The model occupies the main canvas. A narrow inspection panel has visibility controls, selected asset details and a searchable column register. Brass indicates all column candidates; orange indicates selection. Neither color indicates condition. C01-style labels provide accessible alternatives to 3D picking. Stable IDs remain separate from these display labels.

System UI typography is an offline fallback for the existing Public Sans body role. Dark ink text on light paper, visible focus rings, native form controls and reduced-motion support. Mobile stacks model and panel without hiding essential actions. No animation beyond direct manipulation; render on demand.

Acceptance: source geometry visibly loads; canopy hides and shows; highlighted columns pick from canvas and list; isolate and reset work; source metadata is inspectable; reusable GLB has stable IDs; desktop and narrow layouts remain usable.
