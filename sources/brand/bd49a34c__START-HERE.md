# Cypress Command Brand Kit

**Version 1.0 · 20 September 2026**

This package establishes Cypress Command as an **AI-enabled operating systems partner for owner-led businesses**. It contains the public brand system, implementation assets, launch messaging, editable templates, and a separate confidential transition plan.

## The decisions are made

| Role | Approved language |
|---|---|
| Category | **AI-enabled operating systems partner** |
| Primary audience | Owner-operators and operating leaders at small to mid-sized businesses |
| Initial proof domain | Commercial real estate ownership and management |
| Brand promise / primary headline | **Make the work easier to run.** |
| External tagline | **Practical intelligence for real operations.** |
| Launch campaign line | **Build AI into how you actually operate.** |
| Offer path | **Operating System Assessment → Operating System Build → Operating Partnership** |
| Delivery method | **Assess → Design → Install → Operate** |

The campaign line is not the permanent tagline. The offers are commercial products; Assess, Design, Install, and Operate are the delivery phases inside them.

## Operating rules

**Public materials must not explain, defend, or debate the reasons for leaving Orange Ocean.** Use the approved continuity language only, for a limited period, and keep the transition plan private. Cypress Command should stand on its own as a forward-looking operating brand.

The logo artwork in this package uses the approved squared spiral/C mark extracted from the uploaded brand pages; it is not the earlier reconstructed command-link symbol. Its ownership, registrability, and trademark status remain unverified. The live domain `cypresscommand.com` currently resolves, but control, registrar security, legal availability, and social-handle availability still require documented verification. The current public site should be updated to the approved message hierarchy because its present real-estate-only framing is narrower than the new brand position.[1]

## Execution priority

| Classification | Action |
|---|---|
| **Do now** | Engage counsel for entity/trade-name and trademark clearance; confirm ownership and security of the domain and priority social handles; approve the master mark. |
| **Defer** | Public launch, broad announcements, paid promotion, and permanent retirement of old assets until the mandatory launch gates pass. |
| **Delegate** | Legal clearance to counsel; DNS, redirects, email authentication, Search Console, analytics, and directory updates to named technical owners. |
| **Automate** | Uptime checks, redirect tests, form tests, DMARC monitoring, 404 reporting, and post-launch analytics alerts. |
| **Ignore / kill** | A long public explanation, a press campaign about the name change, repeated discussion of the former brand, and speculative rebuttal of old coverage. |

## Launch gates

Do not launch until professional clearance supports the intended name use; the legal-entity and trade-name path is settled; the domain, handles, and account-recovery controls are documented; the new website, email, forms, analytics, and redirects pass testing; and every public factual claim has evidence and approval. The migration plan is operational guidance, not legal advice.

## Highest-leverage next action

**Send the name, mark, intended services, jurisdictions, and current entity structure to trademark/business counsel for a written clearance decision.** Everything else in the kit can move quickly once that gate is closed.
