# Cypress Command — Marketing Site UI kit

Single-page marketing scroll. Sections:

1. `Hero` — cypress grove blue-hour photo, "operating system for real-world businesses"
2. `PositioningTriangle` — three-pillar intersection (physical ops + AI + governance)
3. `HowItWorks` — four-step workflow (Ingest / Observe / Draft / Report)
4. `GroveSection` — partner program with a live roster preview
5. `TrustBar` — compliance strip
6. `ClosingBanner` — "Ground truth. Delivered." sign-off

Signature moves:
- Trailing period on headlines, colored amber
- Bracket meta labels ([01 — POSITIONING], [GROVE ROSTER · Q3 2026])
- JetBrains Mono for all eyebrows, meta tickers, and inline tags
- Fraunces for display, Inter for body — no substitutions

Components live in `/components/*.jsx`. See `/components/Sections.jsx` for the section source.
