# Cypress Command — Property OS UI kit

The operator's command surface. Sidebar-driven web app with 5 core screens:

- **Dashboard** — KPI cards, portfolio grid, cash flow bar chart, live agent activity feed
- **Leases** — full lease pipeline table with [LEASE-###] bracket IDs, tenant, sqft, term, status
- **Maintenance** — work order cards with priority-color left borders, assignee, due date
- **Tenants** — roster of active operators with category, unit, sqft, tenure
- **AI Console** ⭐ — the differentiating surface: terminal + agent cards + input prompt

Uses `Sidebar` + `TopBar` from `/components/Chrome.jsx`, plus every data atom from `/components/Data.jsx`.

Persists the current screen to `localStorage` (`cc:screen`) so refreshes don't lose context.
