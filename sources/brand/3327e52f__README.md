# Reference register

## Current visual authority

- `master-application-board-light.png`: user-supplied light master.
- `master-application-board-dark.png`: user-supplied dark master.
- `master-application-board-light-alternate-upload.png`: additional user upload, preserved without modification.
- `original-visual-reference.png`: original source sheet recovered from the referenced conversation.
- `original-visual-reference-user-upload.png`: subsequent direct upload of the source sheet, preserved separately.
- `exploration-editorial.png`, `exploration-technical.png`, `exploration-archival.png`, `exploration-digital.png`: historical expression studies supplied by the user. Font names and status labels in these studies are not additional production systems.

The current user request and Terra-logo clarification take precedence over text embedded in these images and over any previous brand release. The new typography uses the master-board families. Exact source-brief values govern ambiguous or inconsistent raster labels. The dark board guides composition; production dark roles use the source night palette plus measured contrast corrections.

The images contain illustrative client names, financial/operating metrics, claims, photographs and drawings. Inclusion is for reference, not verification of those facts or clearance for external reuse. Images remain unchanged so their provenance is clear.

## New editable derivatives

`application-board-light.svg` and `application-board-dark.svg` are schematic plates generated from this v1 system. They are not reproductions of the supplied boards. They deliberately avoid live metrics. Edit with a vector editor and install the bundled fonts for matching typography; the master-board PNGs remain the richest visual references.

## Historical geometry evidence

`legacy-logo-rules.md` documents the prior vector geometry and export sizes. Its old palette restrictions are superseded by the user's current instructions and must not constrain this release. The new production logo variants are `assets/logos/cc-v1-*`.
