# Logo masters

Use `cc-v1-horizontal-light.svg` or `cc-v1-horizontal-dark.svg` for this design system. Light: Terra symbol #A44E12 with Ink wordmark #1E1B16. Dark: night Terra symbol #D2802F with Paper wordmark #F4EFE2. Standalone marks are `cc-v1-mark-light.svg` and `cc-v1-mark-dark.svg`.

The Terra treatment is expressly authorized in the current conversation. Existing geometry and outlined letters are preserved; only fill values change. Original `cc-04c-*` files are kept for provenance, not as a competing palette standard. SVG masters scale without loss. Keep the built-in clear space; do not reconstruct the wordmark from a font.

Horizontal exports have a 732 x 256 viewBox including clear space. The original symbol envelope is 168 x 160 units with a 48-unit core. Minimum horizontal export: 260 CSS px / 65 mm. Use a standard standalone mark at 24 px high or larger. Tiny micro originals remain historical assets; a new Terra micro release would need dedicated size testing.
