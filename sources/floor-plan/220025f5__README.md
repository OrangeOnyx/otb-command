# Portable model source

Requires **Node.js 22.18 or newer**. No npm install or network access is needed. Keep this `source` folder beside the packaged `vendor` folder.

From the unpacked `OTB_Column_Twin` folder, verify the rebuild without changing any model files:

```powershell
node ./source/build_twin_model.mjs --check
```

Rebuild the GLB, viewer metadata, conversion report and column register:

```powershell
node ./source/build_twin_model.mjs
```

The script resolves all paths from its own location, so the commands also work when the package is moved. The rebuild writes four outputs one folder above this source folder: `model.glb`, `model-data.json`, `model-report.json` and `columns.csv`. The CSV always regenerates from the same final column records as the viewer metadata, preserving its existing header names. Reload the viewer after rebuilding. The report includes binary, buffer, node-reference, finite-value and source-hash checks; browser visual acceptance remains a separate check.

`--check` compares the regenerated GLB byte for byte and checks the CSV values against the regenerated column records, without writing files. CSV comparison permits equivalent quoting, a UTF-8 BOM, either newline style and equivalent numeric formatting.

## Inputs

- `On_The_Boulevard.native.fml`: byte-preserved Floorplanner export, including both floors and all designs.
- `column-analysis.json`: final candidate-column definitions and stable IDs, referencing ground-floor design 241952337. Its source-path field is package-relative; the original source SHA-256 is preserved.
- `build_twin_model.mjs`: source-preserving geometry converter using the bundled Three.js polygon triangulation.

## Editing and provenance

Preserve a copy of the native export before geometry edits. Editing or replacing the FML requires refreshing the column wall indices, source GUIDs, dimensions and source hash in `column-analysis.json`; the script deliberately rejects stale analysis. Column detection itself is not rerun by this converter. Labels and review notes can be changed in the analysis JSON without changing the source geometry.

All dimensions remain in source centimeters until the converter writes meter-based, Y-up glTF geometry. Source columns are candidates, not field-verified structural supports. The second floor is retained in the native file but omitted from the GLB pending registration verification. The source-height and canopy-thickness limitations are recorded in the generated report.
