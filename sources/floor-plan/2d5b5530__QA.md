# Release checks

September 23, 2026. Scope: portable source-derived model and local viewer.

## Model and data

- Native FML byte-preserved; source SHA-256 is recorded in model-data.json and model-report.json.
- 37 unique, individually named column assets linked to 154 original wall segments. No opening-bearing walls were classified as columns.
- GLB header, binary lengths, buffer views, accessors, node references, finite values and IDs validated.
- Independent Three.js GLTFLoader import passed: 42 meshes, 37 column meshes, 29,949 triangles, 2,201,460 bytes.
- 166 door voids and 91 window voids preserved; six source overhangs clipped and recorded.
- Portable source converter reproduces a byte-identical GLB and validates the 37-row CSV semantically. Rebuild regenerates GLB, JSON metadata, report and CSV.
- Independent geometry review checked all 37 eye camera positions: all are on the modeled walkway with clear sightlines to the selected column. Final eye target is centered on the selected column to avoid narrow-view framing failures.

## Browser acceptance

- Actual WebGL rendering checked in the Codex browser, at desktop size and a 390 × 844 responsive viewport. Temporary viewport override reset.
- Verified marker selection, direct 3D column picking, focus, canopy visibility, column isolation, plan view, search, C25 review notice, labels, next-column navigation and keyboard movement.
- Corrected narrow-screen overview cropping, eye-level marker clutter, end-wing camera placement and picking through opaque walls/canopy.
- No console errors or warnings in the final rendering check.
- Controls use native buttons, labeled inputs, visible focus and an accessible column register. No continuous animation or external font/network dependency.

## Review disposition

Independent source review completed. The UI detector's functional small-text finding was corrected. Accent-border findings referred to the inherited OTB masthead and loading icon, not content cards; retained. No product metrics, tenant status or maintenance condition were invented.

## Limits

This checks digital consistency and viewer behavior, not physical accuracy. All candidates remain unverified in the field. C25 has a lower-confidence classification. Roof details, catalog assets, second-floor registration, geographic placement and operational data connections remain outside the delivered model. Free movement can pass through geometry.
