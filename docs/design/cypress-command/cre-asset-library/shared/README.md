# Shared reusable templates

Reserved template categories follow the taxonomy. These folders intentionally contain no invented property geometry. A template has no implied installed position, measured size, tenant assignment or operating state. Derive an OTB instance from registered source geometry before adapting its reusable structure for other properties.

Keep canonical native source files and existing application/runtime modules in their current governed homes until the repo-wide migration mapping identifies a justified target. `.gitkeep` files only preserve the reserved directory layout.
