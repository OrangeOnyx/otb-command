## OTBC-AGENT-001 · 🏛 Concierge (grounded Q&A)
- **Surface:** AI-1 sheet, default chip. **Model:** claude-opus-4-8, adaptive
  thinking, effort medium, max_tokens 2500, ≤4 tool rounds, streaming.
- **System prompt:** persona + shared `CORE` rules + prompt-cached property
  dossier (`api/_context.mjs`, ~7.6k tokens, cache_control ephemeral,
  regenerated by `npm run concierge-context` — never hand-edited).
- **CORE rules (api/concierge.js:27-35):** ground every answer in dossier +
  `<live_state>` (live supersedes dossier); audit-grade facts immutable (GLA
  62,883 / 27 units / variance 99-11797 / "Arnould" street vs "Arnold Heights"
  subdivision — never "corrected"); never invent numbers; **never do arithmetic
  — call `run_calc`** and narrate only returned figures; surface anomalies,
  don't fix them; executive register.
- **Tools:** `run_calc` only.
- **Grounding data:** static dossier + live `property_state` digest (operator
  overrides only) woven into the final user turn — keeps the cached system
  prefix byte-stable (cache-safe design).

## OTBC-AGENT-004 · Auto-trigger cron (proactive, non-conversational)
- `api/auto-trigger.mjs` daily: pure detectors (`lib/autotrigger.js`) emit
  candidates — holdovers (end < today), renewal horizon (≤180d), occupancy
  floor (<85% SF-weighted) — each idempotently opens ONE AI-1 thread via
  `open_trigger_thread` (unique `trigger_source`), routed to the right agent
  persona with one seeded assistant message. Live catch: found the 115/117
  renewal window; operator entered discussions.
- Monthly jobs: deterministic Owner Intelligence Brief (NO LLM — brief.js) and
  ledger rent charges. All idempotent.

## OTBC-AGENT-005 · C3 stall classifier (offline VLM pipeline)
- `tools/c3-stalls.py`: per-camera stall quads → perspective crops → **one
  Haiku request per frame** (all stalls labeled, strict JSON schema) →
  JSONL. Hourly sampling of 300s frames; idempotent; nightly scheduled.
  Classifier hygiene: unclear/stale never count as occupied or empty
  (lib/occupancy.js). Prompt authored in the tool; validated against
  known-ground-truth frames before go-live.

## Known prompt failures / hallucination risks (observed + mitigated)
1. **Arithmetic hallucination** — the original risk class; mitigated by
   run_calc + fail-closed guardrail (donor synth-validator M1/M2 tightened:
   ints >12 not ignorable, tolerance 0.5%).
2. **"Correcting" legal proper nouns** (Arnold Heights → Arnould) — a real
   incident class ("was poisoning export JSON", fixed 2026-07-08 audit);
   now pinned in CORE rules + data-integrity tests.
3. **Stale-holdover narration** — manager persona line fixed 2026-07-16 after
   SOT reconciliation.
4. **Refusal/interruption handling** — canned decline; interrupted streams
   marked "⚠ interrupted"; early failures drop the user turn for clean retry.
5. **Windows encoding** — Task Scheduler cp1252 stdout killed a classify run
   after ONE frame while looking successful (PYTHONUTF8=1 lesson) — a pipeline
   failure mode, not a prompt one, but it silently corrupts agent-fed data.
